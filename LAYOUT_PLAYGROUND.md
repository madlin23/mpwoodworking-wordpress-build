# MP Woodworking – Layout Spielwiese

Diese Datei wurde angelegt, um eine neue Git-Version (Sicherungspunkt) zu erzeugen. Sie dient als Ihr persönlicher Leitfaden für Layout-Experimente im WordPress-Theme.

## Tipps für Ihre Layout-Anpassungen

1. **Child-Theme nutzen**: Nehmen Sie alle CSS-Änderungen in `wordpress-themes/mpwoodworking-child-theme/style.css` vor.
2. **Gutenberg-Patterns**: Nutzen Sie die registrierten Block-Patterns (Werte-Karten, CTA-Banner) direkt im WordPress-Editor für schnelle Layout-Aufbauten.
3. **Sicherheit**: Sie können über das Management-UI jederzeit zu dieser oder einer früheren Git-Version zurückkehren, falls ein Experiment fehlschlägt.

Viel Erfolg beim Gestalten!
